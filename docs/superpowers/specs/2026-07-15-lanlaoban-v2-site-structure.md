# 懒老板 v2 — 全站页面结构定稿

## 一、导航栏（新结构）

```
[懒老板 Logo]  |  IP操盘手  |  产品导演  |  定价  |  关于  |  [登录 / 用户头像]
```

导航只保留 5 个入口，剩余功能藏到用户登录后的操作台里。

---

## 二、页面清单

### 顶层页面（5页）

| 页面 | 路由 | 说明 |
|------|------|------|
| **首页** | `/` | 品牌着陆页。Hero + 两个产品入口 + 三步流程 + 案例 + 定价预览 + 引流 |
| **IP操盘手** | `/ip-manager` | 产品详情页。AI采访介绍 + 流程演示 + 完整定价表 + FAQ |
| **产品导演** | `/product-director` | 产品详情页。三选一引导 + 风格库 + 母片规格 + 三层体系定价 |
| **定价** | `/pricing` | 左右分区：IP订阅价目表 / 产品导演项目包+会员+算力。含连续包月/包年标签 |
| **关于** | `/about` | 团队/案例/联系方式 |

### 用户操作台（登录后，4页）

| 页面 | 路由 | 说明 |
|------|------|------|
| **我的IP** | `/dashboard`（现有） | AI采访入口 + IP档案 + 内容日历 + 素材交付记录 |
| **我的项目** | `/projects`（新增） | 产品视频项目列表 + 状态追踪 + 预览/下载 |
| **设置** | `/settings`（现有） | 账号信息 / 订阅管理 / 邮箱偏好 |
| **帮助** | `/faq`（现有） | FAQ + 使用指南 |

### 辅助页面（3页）

| 页面 | 路由 | 说明 |
|------|------|------|
| 服务条款 | `/terms` | — |
| 隐私政策 | `/privacy` | — |
| 404 | 自动 | 自定义404 |

### 旧功能迁移（保留URL，入口从导航移到操作台内）

| 旧路由 | 新归属 |
|--------|--------|
| `/global-supply/*` | 保留访问，导航不展示（从产品导演页面可关联进入） |
| `/brand-promotion` | 并入产品导演产品页 |
| `/digital-human` | 数字人口播功能 → IP操盘手的"口播视频（即将上线）" |
| `/interview` | → 操盘台内的"AI采访"模块 |
| `/diagnose` | → 操盘台的"IP诊断"工具 |
| `/generate/*` | → 操盘台内的"内容生产"模块 |
| `/ai-video` | → IP操盘手的介绍页用 |

## 三、设计规范

### 品牌色
- 品牌橙: `#FF6034`
- IP产品色: `#FF6034`（橙色系）
- 产品导演色: `#2563EB`（蓝色系）

### 禁止
- ❌ 全站任何位置不使用 emoji 作为图标
- ❌ 不使用 emoji 做列表符号、装饰、分隔
- ✅ 统一使用 `react-icons/fi`（Feather Icons）或自定义 SVG

### 字体
- 中文: Noto Sans SC
- 英文/数字: Inter

---

## 四、实施顺序

```
第一波（核心页面，3页）
  ┌ 首页 `/`          → 已改完，部署即生效

  ├ 我的项目 `/projects` → 新建

```

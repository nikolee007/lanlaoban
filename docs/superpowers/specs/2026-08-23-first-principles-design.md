# 六大第一性原理沉淀懒老板 Agent 体系 — 设计文档

> 日期：2026-08-23
> 状态：已批准
> 目标：把「自媒体创作六大第一性原理方法论」沉淀为懒老板 Agent 的全局创作底层逻辑，让所有 skill 生成时遵循。

## 背景

老大（李荪凌）提出六大第一性原理方法论，作为短视频内容创作的人性底层逻辑：

| # | 第一性原理 | 核心主张 |
|---|-----------|---------|
| 1 | 出镜·情绪优先 | 情绪感染力 > 画质颜值，真诚共情松弛 |
| 2 | 流量·选题为基 | 选题价值 > 剪辑技巧，先选对题 |
| 3 | 点赞·认可驱动 | 让用户"看见自己"，触发自我认同 |
| 4 | 评论·槽点制造 | 留表达空间，抛疑问/留争议点，引导评论 |
| 5 | 转发·嘴替 | 说出用户想说不敢说/不会说的话 |
| 6 | 涨粉·价值沉淀 | 持续输出情绪/认知/实用三类价值 |

## 决策

- **归属 Agent**：主体 = AI编剧（4/6 条文案设计逻辑）；AI操盘手承接选题与价值沉淀（2 条）
- **沉淀深度**：全局 KERNEL + 知识库文档（用户已确认）
- **不新建 JSON 知识文件**：六原则是行为准则不是行业数据，进 KERNEL prompt 比进数据文件合适

## 改动清单

### 1. `lib/agent-skills.ts` — KERNEL 注入第 7 条底层准则

KERNEL 末尾追加（保持与现有 6 条同风格，短句）：
- 创作底层逻辑（抓人性，不炫技）：
  - 选题为基：选题价值 > 剪辑技巧，先选对题
  - 情绪优先：口播感染力 > 画质/设备，真诚松弛有共情
  - 认可驱动：内容让用户"看见自己"，触发自我认同
  - 槽点制造：留表达空间，抛疑问/留争议点，引导评论参与
  - 嘴替转发：说出用户想说不敢说/不会说的话
  - 价值沉淀：持续输出情绪/认知/实用三类价值

# NAS 多媒体中心（路线 A：绿联软件层 + 免费合法内容源）— 设计文档

> 日期：2026-08-23
> 状态：已批准
> 目标：把绿联 DXP4800（192.168.1.55）变成家庭多媒体中心，复用现有软件层，接入合法免费内容源，零软件安装成本。

## 硬件/软件现状（实测）

| 项 | 值 | 结论 |
|----|----|------|
| CPU | Intel N100 | 支持 QSV 硬件转码 |
| 内存 | 15G（已用 6.4G，剩 9G） | 充裕，媒体服务 ~110MB 无压力 |
| 磁盘 | /volume1 7.2T，剩 4.9T | 片库空间充足 |
| 软件层 | 绿联影视中心 + 音乐中心（media_serv/music_serv 已运行） | 零新增软件 |
| 代理 | mihomo:7890 + WARP:8899 本机运行 | 刮削 TMDB 走本机代理 |
| 外网 | cloudflared 隧道已运行 | 远程访问可用 |

## 设计决策

- **路线 A**：不装 Jellyfin/Navidrome，复用绿联影视中心 + 音乐中心
- 片源：Internet Archive（公版老片/纪录片）、Jamendo（CC 音乐）、OpenFlixr 等**合法免费源**
- 边界：公版老片/纪录片/独立电影/CC 音乐/古典为主，非新片首发；新片走广告流媒体（Pluto/Tubi）
- 目录：`/volume1/媒体/电影` + `/volume1/媒体/音乐`（用户可读目录，非系统哈希目录）
- 媒体库：绿联 UI 添加上述目录 → 自动扫描刮削（走 mihomo 代理访问 TMDB）
- 自动化：crontab 每周增量抓取新片/新曲

## 目录规划

```
/volume1/媒体/
  ├── 电影/      ← Internet Archive / OpenFlixr 公版影片
  └── 音乐/      ← Jamendo / IA 音频 / 古典
```

## 内容源

| 源 | 类型 | 抓取方式 |
|----|------|---------|
| Internet Archive | 公版电影/纪录片 | `ia` 命令行工具按关键词批量下载 |
| OpenFlixr / 公版库 | 公版独立影片 | 直链 |
| Jamendo | CC 授权音乐（50万+） | API 按风格批量拉取 |
| IA 音频 | 古典/老唱片 | 直链批量下载 |
| Radio Browser（附加） | 全球免费电台 | 网页/客户端，不占片库 |

## 运行机制

1. **常驻层**：绿联媒体服务 + 代理（已运行，零新增）
2. **定时层**：crontab 每周触发抓取 → 跑完即退，不驻留
3. **按需层**：播放时 N100 硬件转码

## 实施步骤

1. SSH 建目录 `/volume1/媒体/电影` + `/volume1/媒体/音乐`
2. 安装 `ia` 工具（如缺）
3. 抓第一批片源（公版电影 3-5 部 + CC 音乐专辑若干）
4. 配置 crontab 定时增量任务
5. 指导在绿联 UI 添加媒体库目录 + 开启刮削（需管理员 UI 操作）

## 验证 Gates

1. 目录创建成功，媒体文件落盘且非空
2. 抓取工具可执行，首批内容下载完成
3. crontab 定时任务已配置
4. 绿联媒体库添加步骤给出可执行 UI 指引

## 不做的事

- ❌ 不装 Jellyfin/Plex/Emby/Navidrome（与现有软件层重叠）
- ❌ 不碰盗版下载渠道/BT/磁力站
- ❌ 不动现有 6 个 Docker 容器（score2midi/hermes/siyuan/choir/qinglong/cloudflared）
- ❌ 不改动系统代理配置

## 为什么要做老板IP（P3）

**页标题：** 为什么老板必须做自己的IP？

**核心信息：** 老板本人，就是门店最便宜、最有说服力、最高回报的广告位

**页面文字：**

1. **老板是最好的代言人**
   - 真人真店真手艺，信任感是任何明星广告给不了的
2. **内容资产是自己的**
   - 粉丝、账号、内容沉淀成私有流量资产，越做越值钱，不依赖任何平台投放
3. **一次拍摄，反复获客**
   - 一条成片挂全平台，24 小时不间断替你吆喝
4. **少量投入 = 大回报**
   - 用 AI 把内容生产成本打到接近零，小预算也能做品牌级的营销

**🔵 招商版引导：** 帮老板解决这个刚需，就是我们这门生意的全部机会。

## 现状痛点（P4）

**页标题：** 现实是：99% 的老板，想做却做不起来

**核心信息：** 三座大山，拦住了实体老板的线上路

**页面文字：**

**1. 内容迷茫**
- 不会拍、不会写、不会剪——老板账号、内容、素材一头雾水
- 不知道发什么：产品？日常？人设？什么都想发，什么都发不对

**2. 平台迷茫**
- 抖音、视频号、小红书规则琐碎：开通、发布、挂车、投流无从下手
- 好不容易会一个平台，规则又变了

**3. 变现迷茫**
- 什么时候做内容、什么时候开直播？用户怎么沉淀成私域？
- 短视频有了播放量，但不知道怎么变成到店客流和订单

**页脚金句：** 好产品被锁在店里，线上流量一分没吃到。

## 懒老板方案（P5）

**页标题：** 懒老板一站式方案：您专注经营，内容交给 AI

**核心信息：** 每个老板专属的运营编导 Agent——越用越懂你，持续产出脚本与成片

**页面文字：**

1. **专属运营编导 Agent**
   - 账号沉淀你的品类、话术、风格，AI 越用越懂你，相当于配了「运营+编导+剪辑」团队
2. **数字人替老板出镜**
   - 上传老板本人照片生成数字人（非虚拟网红），一键口播成片，肖像使用签授权
3. **一键做企宣**
   - 上传产品/门店素材 → AI 写文案 → 图文成片 → 一键数字人口播 → 邮箱交付
4. **平台 0 操作，直接出片**
   - 抖音 / 视频号 / 小红书多平台分发，发布链路一站式解决
5. **长线共赢，多平台运作**
   - 内容资产沉淀、持续复用、多平台放大，越合作越值钱

**配图建议：** 三步出片流程图（上传 → AI生成 → 多平台分发）

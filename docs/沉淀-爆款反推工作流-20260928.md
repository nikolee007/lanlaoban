## 三、它到底怎么做的（五步流水线，原文口径）

```
丢视频 → 反推提示词 → 生视频 → 包装视频 → 成片
```

**关键在第二步「反推」**（原文定义）：不是让 AI 照着原视频画一条一样的，而是把画面里的
**主体 / 场景 / 动作 / 镜头运动 / 光影氛围**一样样拎出来，整理成**结构化提示词**——
「这套提示词本身不包含原视频的画面，只描述这条视频是怎么构成的」，拿它去任何 AI 视频工具生成，
得到风格接近、内容全新的视频。原文一句话：「学的是手法，做的是自己的东西——反推和抄袭，边界就在这里。」

**技术链路（原文实测披露）**：

| 环节 | 用什么 |
|---|---|
| 拿到视频 | 给一条抖音链接或上传文件，Agent 自己下载 |
| 测参 | `ffprobe` 测比例 / 时长 / 帧率 |
| 看画面 | **均匀抽帧** + 逐帧读画面 |
| 听声音 | **Whisper** 把音频转文字 |
| 出结构化提示词 | 一句话核心提示词 + 场景设定 + 主体描述 + 按时间轴的动作情节 + 氛围情绪 + 画质 |
| 出分镜 | 例：**9 个镜头**，每格带时间轴 / 画面要素 / 镜头语言 / 衔接提示 |
| 出防崩项 | 负面提示词（防崩脸、防多余文字水印）+ 角色设定档案 |
| 生成 | 需 API Key；原文用 **seedance 2.0** 实测生成；提示词丢豆包也能免费试 |

**实测数字（原文）**：Skill 安装（4 脚本 + 2 文档）**7 分 55 秒**；一条链接到「六件套」报告 **29 分钟**；
另一篇的成品工具：**60 秒视频 4 分 37 秒出片**，支持**素材混剪 / 智能配图 / 数字人口播**三种模式，
流程带**违规检测**。

**Skill 形态的一句关键提醒（原文）**：「提示词会过期，而拆解出来的判断力可以带走」——
即他们要沉淀的是**拆解框架（判断力）**，不是某条具体提示词。

## 四、对照我们（懒老板）现状 —— 差在哪，我们有什么

| 能力 | WorkBuddy 路线 | 懒老板现状（据 `docs/`+代码级核实） | 差距类型 |
|---|---|---|---|
| 爆款反推（链接→结构化提示词+分镜） | ✅ 有（Skill + 4 脚本） | ❌ **无此入口** | **缺能力** |
| 视频参数/抽帧 | ffprobe + 均匀抽帧 | ✅ 我们有 `ffmpeg`（NAS 现成，拆解短链那套已验证） | **已有零件** |
| 音频转写 | Whisper | ✅ 有（NAS + Windows RTX2060 夜班可批量） | **已有零件** |
| 分镜脚本输出 | ✅ 9 格分镜 | ⚠️ `/ai-video` 只出**分镜脚本**（不出片），`/brand-promotion/script` 仅 4 段式旁白（无镜头） | **半成品** |
| 生成视频 | 接第三方视频模型（seedance 2.0 等） | ⚠️ 渲染＝**浏览器 Canvas + MediaRecorder 录屏**（照片交叉淡化 + 文字滑入 + TTS 音轨 + 数字人 PiP），**结构上做不出多轨多镜头** | **架构缺口** |
| 三种出片模式 | 素材混剪 / 智能配图 / 数字人口播 | ⚠️ 仅产品可视化一条线真出片（`/brand-promotion`） | **缺模式** |
| 违规检测 | ✅ 有 | ❌ 无 | **缺能力** |

**一句话结论**：**反推层的零件（ffmpeg/Whisper/LLM）我们都有，缺的是"把它接成一条入口"；
真正卡住的是生成层——出片靠浏览器录屏，做不出"接近爆款"的多镜头片。**
⇒ 这正好印证 `lanlaoban-dev` skill 里那条既有判断：**画面切换/多镜头是接线与架构问题，不是能力问题**，
解法是把渲染从"用户浏览器录屏"迁到"提交服务端渲染 → 回传 MP4"（NAS 已有 HyperFrames 多场景渲染线，实测 1080p 竖版 17.7s 片 61 秒渲染、**¥0**）。

## 五、可落地三步（挂进队列，不在这里空谈）

1. **【零成本·可当天做】爆款反推入口 MVP**：新增 `/reverse`（或并入 `/ai-video`）——
   输入链接/上传视频 → `ffprobe` 测参 → 均匀抽帧 → Whisper 转写 → 输出**结构化提示词 + 时间轴分镜表**（Markdown/JSON）。
   零件全是现成的（NAS ffmpeg + Whisper + 我们自己的 LLM 网关），**不碰 Vercel 跑 ffmpeg 的架构纪律**（渲染/转写走我们服务器）。
2. **【需老大拍板】生成层接线**：反推出的提示词要出片，必须接**视频生成模型**（付费）或走 **HyperFrames 服务端渲染**（¥0 但非 AI 生成）。
   两条路的成本与可行性要一份对照表再定 ✓
3. **【合规前置】反推 ≠ 抄袭**：对外话术直接采用原文边界（"只描述构成，不含原画面"），
   并在产品内加**违规/雷同检测**（对标 WorkBuddy 的违规检测），避免用户拿它做搬运。

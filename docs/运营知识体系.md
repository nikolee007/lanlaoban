# 懒老板 · 运营知识体系（Agent 训练底座）

> 本文件是「数据写入 + Agent 训练」的运营方法论底座，由老大（李荪凌）操盘 0-1 经验 + AI 整理。
> Agent（AI 操盘手/广告导演/编剧/数据专家）据此产出内容；老大后期基于反馈数据精细化校准。

---

## 一、商业定位

**懒老板 = 老板版的 LibTV**
- 目标：实体店老板（不是专业创作者）
- 核心：**操盘 0-1 经验的 Agent** 主导老板 IP 短视频 + 产品可视化
- 差异化（LibTV 没有的）：**老板克隆分身 + 产品可视化联动**
- 变现：算力差价（平台接入便宜 API，用户充值买算力，赚差价）+ 订阅

**护城河**：老大 8 年+ 操盘实战（200+ IP、全网 10亿+ 流量）沉淀为 Agent 运营知识，越用越懂。

## 二、商家极简链路（人力环节交给 AI）

```
① 线上采访/口述门店情况（interview）
② 少量实拍素材 + 人脸/口播采样（克隆分身 + 声音克隆）
③ 提交门店基础资料（IpProfile：地址/产品/活动/价位）
   ↓
AI：文案脚本（Agent）→ 克隆分身+产品可视化 → 数字人口播成片 → 持续批量交付
```

老板只需做这三件极简动作，其余全 AI。

## 三、内容方法论（Agent 产出铁律）

### 3.1 三大底层准则
1. **可落地、可变现、可批量复制** —— 拒绝无商业价值的纯流量内容
2. **账号生命周期思维** —— 冷启动/成长/成熟变现，差异化策略
3. **风控优先** —— 规避广告法极限词，严禁承诺保本/稳赚/固定收益

### 3.2 8 类标题公式（见 lib/title-formulas.json）
| 类型 | pattern | 适用 |
|------|---------|------|
| 反问痛点型 | 做XX这么多年，为什么YY？ | 制造代入感 |
| 行业内幕揭秘型 | XX行业没人敢说的实话 | 激发好奇 |
| 三点干货避坑型 | 做XX牢记3个关键点 | 实用干货 |
| 案例成果型 | 这家店靠XX，业绩翻倍 | 结果说服 |
| 悬念钩子型 | XX店的老板，有件事你一直不知道 | 强钩子 |
| 数字冲击型 | 做对3件事，XX效果翻倍 | 具体可执行 |
| 身份对号型 | 如果你是XX老板，这条必看 | 精准筛人 |
| 热梗反差型 | 别人都在XX，这个老板却在XX | 反差抓眼 |

### 3.3 3 秒钩子设计
开篇 3 秒必须有效钩子（痛点暴击/认知冲突/直击反问），禁止缓慢抒情开场。

### 3.4 口播适配
台词短句表达；`/` 短暂停顿、`//` 长停顿；适配单人数字人口播，不设计复杂场景/多人/高难度运镜。

### 3.5 合规红线（见 lib/forbidden.json + getComplianceGuidance）
- 极限词：最/第一/顶级/100%/零风险/全网最低 等禁用
- 功效违禁：根治/永不复发/包好/治愈 等禁用
- **严禁承诺**涨粉/客流/营业额/收益，只交付内容与工具价值

## 四、行业知识地图（9 行业，见 lib/pain-points.json + title-formulas.json）

餐饮 / 装修 / 工厂 / 门店 / 美业 / 教育 / 健身 / 汽修 / 宠物
- 每行业有：经营痛点、客户痛点、获客痛点、标题公式例子、违禁词

## 五、三大短板对策（产品必须遵守）

| 短板 | 对策 |
|------|------|
| 素材质量下限在客户手里 | 《素材拍摄简易指南》+ 明确"成片效果和原始素材挂钩" |
| 同质化风险 | 采访环节抓门店独有卖点（老店故事/特色产品/本地差异化），拒绝通用模板 |
| 过度承诺流量 | 只承诺稳定批量产出内容，绝对不打包票涨粉/到店/营业额 |

## 六、四大 Agent（护城河，后续建设）

| Agent | 职责 | 调用能力 |
|-------|------|---------|
| AI 操盘手 | 账号阶段判断、内容策略、批量排期 | 知识库 + 画像 + 生成引擎 |
| AI 广告导演 | 镜头/脚本/产品可视化导演 | 克隆分身 + 产品可视化 |
| AI 编剧 | 标题/文案/口播脚本 | 标题公式 + 痛点 + 合规 |
| AI 数据专家 | 播放/完播/转化分析，回填画像 | 反馈飞轮数据 |

统一入口：`/api/clone/generate`（Agent 预留）

## 七、定价分层（配合算力体系）

|----|------|------|

## 八、数据飞轮（越用越懂的技术底座）

```
商家画像(IpProfile) + 生成记录(CloneGeneration) + 反馈(AgentFeedback: 采纳/爆款/未用)
        → 知识库/画像回写 → Agent 生成时注入 → 产出更贴合 → 更多反馈
```

- 知识库：lib/title-formulas.json（8 公式×9 行业）、pain-points.json（10 行业）、oral-phrases、forbidden.json
- 反馈入口：/api/agent/feedback（前端"采纳用/爆款潜力/不用"按钮）

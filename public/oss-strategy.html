我们不发明能力，我们编排势能。

只要别人已经做出来、做得好、还能合法商用，我们的正确动作是接过来，不是重做一遍。我们只自建别人拿不走的那部分：数据、流程、交付、信任。

一、为什么必须先立这条理论

能力正在商品化数字人/声音克隆/视频生成，三年前是壁垒，今天是一个开源仓库加一台显卡。仅「数字人·口播」一个方向就有 10+ 可选项，最高 1.9 万星（见下表 D 类）。
能力的边际成本趋零多服务一个客户几乎不增加成本 →「我有这个能力」收不了钱。同类数字人 App 订阅已被打到 68~98 元/月甚至终身 98 元。
只有四样抄不走数据（谁效果好、为什么好）、流程（一条链能自动跑完）、交付（客户拿到成片、能开票、能售后）、信任（品牌/老板 IP/供应链）。
推论把时间花在自研能力上 = 花在最容易被抄、最不产生复利的地方。钱和精力全压到那四样上。

二、借势四律

势差律势在哪

任何能力，只要别人已做出来，自己做 = 成本高 N 倍、质量低 M 倍。用四个硬指标判势是否成熟：成熟度 / 活跃度 / 可商用 / 可调用。

许可律能不能借

许可证是入场券，不是免责声明。四类势四种借法：可商用→直接用；有附加条款→只做内部工具；传染性（GPL/AGPL）→高危，不链接进闭源产品；不可商用/无许可→只学结构不抄代码。

接口律怎么借

不能被 Agent 调用的能力等于没借到。三种借法：直接用 / 自部署 / 抄结构。三条硬规矩：适配层隔离、永远留第二供应商（并真的切换测过）、成本耗时可计量。

成势律借了之后

借势的终点不是省钱，是把势能固化成自己的资产：模板库 / 流程 / 标准 / 数据。势能会衰减（停更/涨价/封号），故必须建势能台账，季度复评。

三、借势决策闸门（五问 · 顺序不能换）

#问题是 →否 →
1这是我们的护城河吗？（数据/流程/交付/信任）自建，且做到极致进第 2 问
2有成熟开源/平台能力吗？进第 3 问自建
3许可可商用吗？（抓 LICENSE 原文）进第 4 问找替代 / 只学结构
4能以接口形式被 Agent 调用吗？进第 5 问找有接口的替代
5借的单位成本 < 自建（成本+维护+机会成本）？借自建并记录理由

灵魂在第 1 问：护城河一律自建，其余一律先看能不能借。「自建」不是默认答案，而是唯一例外的答案。

四、不借清单（反面教训）

  • 不借无许可证项目（默认保留版权，商用即侵权）
  • 不借 AGPL/GPL 进闭源产品（传染）
  • 不借「停更+无社区」却卡在关键链路上的（势能已衰减成负债）
  • 不借没有接口的（不能自动化 = 人力黑洞）
  • 不把客户关系/核心数据托管给第三方（护城河只能自建）
  • 不为「看起来先进」而借（与交付形态对不上就是玩具）
  • 不留单点（NAS_CLONE_API 就是反面教材）

六、选型结论（4 路调研 + LICENSE 原文核验）

45 项候选逐项抓取仓库 LICENSE 原文核对。结论：不是所有"开源"都能商用，其中 5 项属法务阻断。

环节结论理由
成片渲染·包装HyperFrames（Apache-2.0）逐条核对无附加条款；官方明示 no per-render fees；本机已实测跑通（17.87s/1080p 渲染 61 秒）
配音（中文）已用 edge-tts（¥0）起步 → GPT-SoVITS(MIT)/CosyVoice(Apache) 做克隆克隆需 GPU；index-tts 为 bilibili 自拟协议（月活 1 亿阈值，我们不触发）
数字人·口播MuseTalk（MIT）主 + LatentSync（Apache）精修唯一同时满足「照片→说话 / 许可干净 / 4GB 显存起 / V100 实时 30fps+」
视频素材生成先买 API（万相 720P ¥0.42/秒、可灵数字人 ¥0.4/秒）月产 < ~900 条 5s 片段时，API 比自建便宜（AutoDL 4090 ¥1,956/月 ≈ 932 条）
自动发布social-auto-upload（MIT）许可干净，但平台风控是最大业务风险（浏览器自动化违反平台协议，有限流/封号风险）
编排自有代码（Next.js + Turso + 腾讯云 worker）n8n 的 SUL 只允许自用；Dify 做多租户需书面授权

八、架构（五层）

① 控制面Vercel + Next.js：只做编排/UI/回调/成本记账 —— 绝不在这里跑 ffmpeg 或长轮询
② 状态层Turso：batch → job → job_step（provider / external_task_id / lease 租约 / 幂等键）
③ 执行面 A腾讯云 Docker（CPU 常驻）：TTS + ffmpeg 合成 + 字幕烧录 + 转码 + 上传 + 发布
④ 执行面 BGPU（按需，非常开）：默认"无 GPU、全 API"，量上来后作为可插拔降本模块插入
⑤ 外部引擎统一适配层 submit()/poll()，换供应商只改配置，不改业务表

三条纪律：适配层隔离／幂等键 + 租约锁（避免重复调用付费 API 造成重复计费）／失败指数退避 3 次 → 死信表 + 告警。

我们不发明能力，我们编排势能。

只要别人已经做出来、做得好、还能合法商用，我们的正确动作是接过来，不是重做一遍。我们只自建别人拿不走的那部分：数据、流程、交付、信任。

一、为什么必须先立这条理论

能力正在商品化数字人/声音克隆/视频生成，三年前是壁垒，今天是一个开源仓库加一台显卡。仅「数字人·口播」一个方向就有 10+ 可选项，最高 1.9 万星（见下表 D 类）。
能力的边际成本趋零多服务一个客户几乎不增加成本 →「我有这个能力」收不了钱。同类数字人 App 订阅已被打到 68~98 元/月甚至终身 98 元。
只有四样抄不走数据（谁效果好、为什么好）、流程（一条链能自动跑完）、交付（客户拿到成片、能开票、能售后）、信任（品牌/老板 IP/供应链）。
推论把时间花在自研能力上 = 花在最容易被抄、最不产生复利的地方。钱和精力全压到那四样上。

二、借势四律

势差律势在哪

任何能力，只要别人已做出来，自己做 = 成本高 N 倍、质量低 M 倍。用四个硬指标判势是否成熟：成熟度 / 活跃度 / 可商用 / 可调用。

许可律能不能借

许可证是入场券，不是免责声明。四类势四种借法：可商用→直接用；有附加条款→只做内部工具；传染性（GPL/AGPL）→高危，不链接进闭源产品；不可商用/无许可→只学结构不抄代码。

接口律怎么借

不能被 Agent 调用的能力等于没借到。三种借法：直接用 / 自部署 / 抄结构。三条硬规矩：适配层隔离、永远留第二供应商（并真的切换测过）、成本耗时可计量。

成势律借了之后

借势的终点不是省钱，是把势能固化成自己的资产：模板库 / 流程 / 标准 / 数据。势能会衰减（停更/涨价/封号），故必须建势能台账，季度复评。

三、借势决策闸门（五问 · 顺序不能换）

#问题是 →否 →
1这是我们的护城河吗？（数据/流程/交付/信任）自建，且做到极致进第 2 问
2有成熟开源/平台能力吗？进第 3 问自建
3许可可商用吗？（抓 LICENSE 原文）进第 4 问找替代 / 只学结构
4能以接口形式被 Agent 调用吗？进第 5 问找有接口的替代
5借的单位成本 < 自建（成本+维护+机会成本）？借自建并记录理由

灵魂在第 1 问：护城河一律自建，其余一律先看能不能借。「自建」不是默认答案，而是唯一例外的答案。

四、不借清单（反面教训）

  • 不借无许可证项目（默认保留版权，商用即侵权）
  • 不借 AGPL/GPL 进闭源产品（传染）
  • 不借「停更+无社区」却卡在关键链路上的（势能已衰减成负债）
  • 不借没有接口的（不能自动化 = 人力黑洞）
  • 不把客户关系/核心数据托管给第三方（护城河只能自建）
  • 不为「看起来先进」而借（与交付形态对不上就是玩具）
  • 不留单点（NAS_CLONE_API 就是反面教材）

五、目标流水线 × 懒老板现状（实测）

#环节目标懒老板现状（2026-09-14 实测）动作
1脚本唯一人工输入已有：四大 Agent 工作台 + brand-promotion/script 在线（真 LLM）+ 标品 V1 规范（24 项质量门）已在
2配音 / 声音克隆个人音色还原、多语言断：MOSS-TTS 自建未就绪（无容器、nginx 无反代）借势
3数字人 / 口播照片→口型驱动半通：克隆分身工作台已建，但依赖 NAS_CLONE_API（内网单点）+ AGNES（额度成本未知）借势
4自动剪辑包装字幕/转场/特效/品牌模板空白：完全没有这一环借势
5成片交付AI 合成 + 交付客户断：task-worker 仅 1 条任务卡 5% 三个月；Vercel 取不到 8898；/task 无 nginx 反代待修

结论：① 脚本环节我们已领先 ② 配音/数字人/剪辑三环可全部借势 ③ 成片交付链是硬缺口（与借势无关，必须自己修通）。

七、合规闸门（先于技术闸门）

AI 生成内容标识《人工智能生成合成内容标识办法》2025-03-07 发布、2025-09-01 已施行（网信办等四部门）：须有显式标识 + 文件元数据隐式标识，并在用户协议中写明标识方法；配套国标 GB 45438—2025。
肖像权授权数字人/声音克隆必须取得被克隆人书面授权（懒老板 2026-09-10 审计已标 P0：当前无授权签署环节）。
出海平台规则YouTube / TikTok 对 AI 生成内容有独立披露要求，需逐平台核对。

结论：这条链能不能上，第一道闸门不是技术，是授权 + 标识。
